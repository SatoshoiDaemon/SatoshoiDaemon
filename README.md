## Engineering Philosophy

I prefer systems that are **understandable, observable and maintainable**.

```text
Reliability         > unnecessary complexity
Automation          > repetitive work
Observability       > guessing
Simple architecture > premature infrastructure
Measurements        > assumptions
Real bottlenecks    > hypothetical scale
```

My goal is not to use the largest possible stack.

It is to choose the architecture that best fits the problem and evolve it when real constraints justify doing so.
